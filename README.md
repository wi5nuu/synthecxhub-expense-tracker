# Syntecxhub_ExpenseTracker_Ashar

This is my Project 1 for the Syntecxhub Internship Program.

## 🚀 Technologies Used
- **React**: Core library
- **styled-components (5.3.11)**: Premium styling & glassmorphism
- **GSAP**: Smooth entrance animations
- **React Router**: Navigation (configured for future scalability)
- **lit-html**: Rendering utilities
- **Lucide React**: Modern iconography
- **Vite-PWA**: Progressive Web App support
- **GitHub Pages**: Deployment

## 🛠️ Features & Requirements
- [x] **Responsive Design**: Mobile-first premium UI.
- [x] **useState**: Form state & expense management.
- [x] **useEffect**: Data fetching from Mock API.
- [x] **useRef**: Auto-focus on title field after submission.
- [x] **useMemo**: Total expense calculation optimization.
- [x] **useCallback**: Optimized event handling for deletes/adds.
- [x] **PWA**: Installable on mobile and desktop.
- [x] **Animations**: Smooth GSAP transitions.

## 📦 Setup & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/USER_NAME/Syntecxhub_Expense_Tracker.git
   ```
2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
